# ReqWeave — 初回起動の手順

このアプリは**開発元（HOWA SHOJI K.K.）の電子署名と、Apple の公証（notarization）を受けています**。
**管理者のユーザ名・パスワードは必要ありません。**

インターネット経由（メール・Web など）で受け取った場合だけ、**初回に 1 回だけ確認のダイアログ**が出ます。
社内の共有フォルダや USB から受け取った場合はその確認も出ません。

---

## macOS の場合

### 1. アプリを置く

受け取った **`ReqWeave-<版>-macos.dmg` をダブルクリック**して開きます。
ウインドウに `ReqWeave.app` とこの手順書が入っています。

その `ReqWeave.app` を**ホームフォルダの中の「アプリケーション」フォルダ**へコピーします。

- Finder のメニューから「移動」→「ホーム」を開きます。
- 「アプリケーション」フォルダが無ければ作ります。Finder のメニューから
  「ファイル」→「新規フォルダ」を選び、名前を **`Applications`（半角・大文字始まり）** にします。
  作成後は「アプリケーション」と表示されます。
- そこへ `ReqWeave.app` をドラッグしてコピーします。
- コピーが終わったら、開いた `ReqWeave` のウインドウを閉じ、
  デスクトップまたはサイドバーの `ReqWeave` を**取り出し**ます（右クリック →「取り出す」）。

> **画面左側の「アプリケーション」（Mac 全体の `/Applications`）には置かないでください。**
> 移動に管理者権限が必要なうえ、その場所では**自動更新ができません**。
>
> **開いた `ReqWeave` のウインドウの中から直接起動しないでください。**
> そこは読み取り専用のため設定の保存も自動更新もできません。必ず上のとおりコピーしてから起動します。

### 2. ダブルクリックする

インターネット経由で受け取った場合、初回だけ次の確認が出ます。

    "ReqWeave.app" はインターネットからダウンロードされたアプリケーションです。開いてもよろしいですか？
    このファイルは "Safari" によりダウンロードされました。
    Apple によるチェックで悪質なソフトウェアは検出されませんでした。

**「開く」** を押します。**管理者のユーザ名とパスワードは求められません。**
2 回目以降はこの確認も出ずにそのまま起動します。

### 3. 起動を確認する

アプリが起動します。以降は通常どおりダブルクリックで起動できます。

## Windows の場合

1. `ReqWeave.exe` を**書き込みができる自分用のフォルダ**へ置きます。
   - 例: `C:\Users\<あなたのユーザー名>\Programs\ReqWeave\`
   - `C:\Program Files` へは置かないでください（書き込みに管理者権限が要り、自動更新ができません）。
2. `ReqWeave.exe` をダブルクリックします。
3. 「Windows によって PC が保護されました」と青い画面が出たら、
   **「詳細情報」** を押します。
4. 現れた **「実行」** を押します。
5. アプリが起動します。次回からはこの操作は不要です。

> Windows 版は電子署名を付けていません。上の警告は**インターネット経由で受け取った場合のみ**出ます。
> ここでも管理者のユーザ名・パスワードは求められません。

---

## うまくいかないときの確認

| 症状 | 確認すること |
|---|---|
| ダウンロードしたファイルの名前が `.dmg` で終わっていない（macOS） | 保存時に拡張子が変わっていないか。`ReqWeave-<版>-macos.dmg` になるよう直してから開いてください |
| 「開発元を検証できません」と出る（macOS） | 受け取ったファイルが壊れているか、古い版の可能性があります。配布元から取り直してください |
| 設定が保存されない・更新できない（macOS） | dmg のウインドウの中から起動していないか。手順 1 のとおりホームフォルダの「アプリケーション」へコピーしてから起動してください |
| 「実行」のボタンが見当たらない（Windows） | 手順 3 の**「詳細情報」**を押したか |
| 起動できない・すぐ終了する（Windows） | スマート アプリ コントロールが有効な端末では起動できません。情報システム部門へご確認ください |
| 起動したがすぐ終了する | 配布元から取り直してください。それでも直らない場合は配布元へ連絡してください |

## このアプリが外部と通信する先

- 設定した AI プロバイダの API（対話・生成のときのみ）
- 更新の確認・取得（GitHub）

上記以外へは通信しません。プロジェクトのデータは**あなたの PC と、あなたが指定した
共有フォルダの中だけ**に保存されます。
