# 受け渡しファイルを開いたときの動き

> ステークホルダーとやり取りする 2 種類のファイルを**ダブルクリックで開いたとき**に何が起きるかを書く。
> 質問票の発行・回答・取込の操作そのものは画面の案内で完結する。
> ここに書くのは**OS によって動きが違う点**と、**担当者が誤って開くと困る点**である。

## 1. 2 種類のファイル

| 拡張子 | 中身 | 誰が開くか |
|---|---|---|
| `.rwvq` | 発行した質問票（ステークホルダーへ渡すもの） | **回答するステークホルダー** |
| `.rwva` | 回答が入って戻ってくるファイル | **システム担当者**（取り込む） |

`.rwvq` はパスコードで保護されている。パスコードは**ファイルとは別の経路**で相手へ伝える。

## 2. ダブルクリックしたときの行き先

| 開いたファイル | アプリの動き |
|---|---|
| `.rwvq` | **回答モード**に切り替わり、パスコードの入力を求める |
| `.rwva` | 担当者側の**取り込みの画面**へ進む（対象のプロジェクトが開かれていなければ、開くよう案内する） |
| それ以外 | 「開けません」と理由を表示して**そのまま使い続けられる**（アプリは終了しない） |

## 3. 担当者の端末で `.rwvq` を開かないこと

**作業中に `.rwvq` を開くと、そのウィンドウは回答モードへ切り替わり、担当者の画面へ戻る操作はありません。**
戻るにはアプリを終了して起動し直します（作業中の内容は保存済みのものが残ります）。

`.rwvq` は回答者へ渡すためのファイルです。中身を確認したいときは、
**アプリの質問票の画面から見る**（発行した内容はプロジェクト側に残っています）。

## 4. Windows と macOS で動きが違う

| | macOS | Windows |
|---|---|---|
| ファイルの関連付け | アプリを置いた時点で有効 | **アプリを一度起動すると**、そのとき自分の利用者領域へ登録される（管理者権限は不要）。**受け取ったファイルより先に一度アプリを起動しておく** |
| アプリを起動した状態でファイルを開いたとき | **開いているウィンドウが**受け取る（ウィンドウは 1 つのまま） | **2 つ目のウィンドウ（別のプロセス）が起動する** |

Windows で 2 つ目が起動するのは**自動更新のためにアプリの多重起動を止めていない**ためです
（更新は「新しい版を起動してから古い版が終わる」手順で行うため多重起動を禁止すると更新できなくなります）。

**同じプロジェクトを 2 つのウィンドウで開いた場合**、片方が処理をしている間、もう片方は
「このプロジェクトを開いている別のウィンドウが処理中です。しばらく待って再実行してください。」と表示します。
データが壊れることはありませんが、**用が済んだウィンドウは閉じる**ようにしてください。

> **Windows の関連付けの登録は実機での確認中です**。
> ダブルクリックで開けない場合は、アプリを先に起動してからファイルをアプリのウィンドウへドラッグしてください。

## 5. 回答モードで不具合が起きたときの診断情報

**回答モードには診断情報を書き出す操作がありません**。回答モードは初期設定なしの
一度きりの利用で、設定画面そのものが無いためです。回答する人が「AI との相談が失敗し続ける」
「ファイルが開けない」などで困ったときは、**担当者が場所を案内して送ってもらいます**。

### 担当者が案内する手順

1. 回答する人に**アプリをいったん終了**してもらう（書きかけの記録を確実に閉じるため）。
2. 次の場所を開いてもらう。**フォルダ名はアプリ名ではなく `net.howashoji.reqweave` です**
   （配布物の識別子と同じ名前）。

   | OS | 場所 |
   |---|---|
   | macOS | `~/Library/Application Support/net.howashoji.reqweave/logs/` |
   | Windows | `%APPDATA%\net.howashoji.reqweave\logs\` |

3. その中の **`app.log`**（と `app.1.log` のような番号つきのファイル）を、ふだんの連絡手段で送ってもらう。
4. 受け取ったら、担当者の端末で内容を確認する（テキストファイルです）。

### 送ってもらう前に伝えること

- **このファイルに回答の中身は入りません**。質問文・背景説明・用語の説明・回答の本文・AI とのやり取り・
  宛先の氏名・ファイル名は**記録していません**（記録するのは「いつ・どの種類の出来事が起きたか」と
  質問票の番号、失敗したときの分類だけです）。
- **パスコードやキーも入りません**。
- 回答の作業は続けられます。ログを送ったことで回答が消えることはありません。

回答そのものを送ってもらう必要はありません。**返送ファイル（`.rwva`）とは別のもの**です。
